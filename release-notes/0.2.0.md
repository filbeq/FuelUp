**New**

- Prices for a whole area: searching a town now lists the stations around it
  (nearby towns included), cheapest or nearest first, with the same rows as
  "Near me".
- "Search this area": move the map while a list is open, then tap the button
  to list the stations in view. On a map showing more than about 80 km, the
  list asks you to zoom in.
- Clearer data date: "Yesterday's prices", or the day and date for older data
  (e.g. "Prices of Tue, Oct 6"), also in Settings → Update data now.
  "Update delayed" appears only when newer prices should already be out.
- About now explains that the Ministry publishes each morning the prices in
  force at 08:00 on the previous day.

**Updating**

- Installs over 0.1.0: your favourites, fuel choice and settings are kept.
